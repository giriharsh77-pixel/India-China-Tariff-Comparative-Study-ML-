# Quality-control checklist (brief §21)

Automated checks are in `src/validation.py` (output: `outputs/metrics/qc_report.csv`, the pipeline stops if a hard check
fails) and `tests/` (18 pytest tests). Status as of the final run on 20 Nov 2026.

| # | Check | Status | Evidence |
|---|---|---|---|
| 1 | All data from identifiable public sources | Pass | `data/data_sources.md`; every raw API response cached in `data/raw/` with request hash |
| 2 | Tariffs refer to the correct importer, origin and product | Pass | TRAINS queried per reporter with partners `000` (MFN), `356` (India), `156` (China) and HS6 codes; parser unit-tested (`tests/test_data_validation.py::test_parse_trains`) |
| 3 | Consistent tariff definitions for India and China | Pass, with disclosed limits | Same rule for both origins (origin-specific preferential series if reported, else MFN). Not captured for either origin: US Section 301/2025 duties, unilateral GSP, trade remedies (`docs/limitations.md`) |
| 4 | HS code consistency across time | Pass | Codes continuous across HS2012/2017/2022 per UNSD correlation tables; 124 strict 1:1 codes used as a robustness check |
| 5 | No duplicate country-product-year rows | Pass | Asserted in `feature_engineering.py`; QC check and unit test |
| 6 | Missing values and outliers handled transparently | Pass | Zero-flow rule, carried-forward tariffs flagged (`tariff_imputed`, 30.0% of candidate rows), log growth with smoothing, train-fold winsorisation; missing rates per column in `data/data_dictionary.md` |
| 7 | No future information in features | Pass | Features dated ≤ t; outcome columns `y_*`/`*_next` never in feature lists (unit test); universe fixed with 2014 data; tariffs filled only forward |
| 8 | Same opportunity universe for both approaches | Pass | QC check "Both approaches score the same universe" (4,785 test candidates) |
| 9 | Same K for both approaches | Pass | `ranking.top_k` used for every method; unit test `test_top_k_per_year_same_k` |
| 10 | Metrics from actual held-out outcomes | Pass | QC checks "Training years strictly precede each decision year" and "Validation and test years disjoint"; all test candidates have realised t+1 outcomes |
| 11 | Charts correspond to final dataset and results | Pass | All figures regenerated by `src/visualisation.py` in the final pipeline run |
| 12 | Simulation works and is labelled as sensitivity analysis | Pass | Headless Streamlit test passed; warnings in app, notebook 08, report §18 and slide 9; historical shortlists in the app use out-of-sample fold scores |
| 13 | Pipeline reproduces principal results | Pass | `python3 scripts/reproduce_results.py` → REPRODUCED (exact match of backtest and regression tables) |
| 14 | Report and presentation numbers consistent | Pass | Both generated from `outputs/results_summary.json`; percentages rounded half-up in both |
| 15 | README explains reproduction from included files | Pass | `README.md` §1 (offline run from cached raw data) |
